# sokol-samples-minc

The [sokol-samples](https://github.com/floooh/sokol-samples) "sapp"
examples as [minc](https://minc.dev) programs, transpiled from the C
sources. Each sample is a single self-contained `.mc` file that builds
against the sokol headers shipped with the minc install
(`import sokol_all;`); no C compiler, no build system.

Native (D3D11/OpenGL/Metal) and browser (wasm/WebGL2/WebGPU).

WASM gallery: <https://spacesofplay.github.io/sokol-samples-minc/>

## Quickstart

install minc if needed:
```
# Windows
powershell -c "irm minc.dev/install.ps1 | iex"

# macOS / Linux
curl -fsSL https://minc.dev/install | bash
```

clone and run a sample:
```powershell
git clone <this repo>
cd sokol-samples-minc
minc run            # lists the samples
minc run cube_sapp
minc run spine_simple_sapp
minc build all      # compile everything into build/
```

flip through all of them:
```powershell
minc run all              # 4 windows at a time; close one and the next opens
minc run all --jobs 2     # narrower
minc run all --seconds 3  # unattended: each one closes itself
```

run one in the browser:
```powershell
minc wasm                   # lists the wasm-capable samples
minc wasm cube_sapp         # build, serve, open (WebGL2)
minc wasm cube_sapp --wgpu  # the same sample against WebGPU
```

Run samples from the repo root; the ones that load files (loadpng,
cubemap-jpeg, spine-*) fetch their assets from `data/`. `minc wasm`
mirrors `data/` into `build/web/`.

## What's here

- `samples/*.mc`: one file per sample: the sample logic transpiled
  from upstream C, concatenated with the transpiled util modules it
  needs (sokol_gl, sokol_debugtext, sokol_fetch, sokol_spine, the
  spine-c runtime, …). Shaders are minc `@shader` functions; the
  sokol-shdc GLSL was ported, not embedded as bytecode blobs.

- `data/`: texture / spine assets the samples fetch at runtime
  (see `data/README.txt` for their licenses).

- `samples/sokol_wasm_host.js`: the browser-side host for `minc wasm`.
  `minc` looks for it next to the sample before falling back to the
  copy inside your install, so the samples get the version they need
  regardless of which minc you have.

- `lib/`: Box3D, which `box3d_simple_sapp` imports and the minc
  standard library does not ship. `minc` searches `lib/` next to the
  project before its own.

- `build.mc`: the build driver (`minc run <name>`, `minc build all`).

- `live-demo/`: the sample gallery GitHub Pages serves; the `pages`
  workflow builds every `samples/LIST_WASM.txt` entry to wasm on push.
